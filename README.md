# Chocified's Space

Personal workspace showcase site — PC build, peripherals, tech stack, and games in one page. Vanilla HTML/CSS/JS, no frameworks.

## Run

```bash
# either works — the second one lets the boot-screen audio autoplay
start index.html
npx serve .
```

## Bits

- Boot screen with an "HONORABLE" flash — click to enter
- Click "Chocified" (top-left) to mute/unmute the music
- Hardware/peripheral cards link to where each part was bought
- Games ticker pauses on hover

Images and music belong to their respective owners.
